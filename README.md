Este repositório disponibiliza os materiais experimentais associados à tese CSAI-4-IoT.

Os materiais estão organizados em `acervo/`, por campanha experimental.

Os resultados das campanhas iniciais e finais permanecem separados. As condições de reprodução e as limitações dos registros de ambiente estão descritas na documentação metodológica.
