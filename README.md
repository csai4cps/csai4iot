- [Acervo organizado: códigos, dados, resultados e análises](acervo/)
- [Quatro pacotes completos das campanhas finais](https://github.com/csai4cps/csai4iot/releases/tag/acervo-2026-10-19)

Não é necessário acessar o Google Drive nem o repositório privado da tese para obter os materiais indexados no acervo. A tese continua sendo editada no Overleaf; este repositório é o endereço público dos materiais experimentais.

Os diretórios anteriores na raiz foram preservados para compatibilidade. Para a distribuição atual, utilize `acervo/`. A cópia integral da distribuição anterior está em [acervo/historico](acervo/historico/).

Os resultados das campanhas iniciais e finais permanecem separados. A disponibilização dos arquivos não representa nova execução de experimentos nem preenche lacunas históricas de ambiente.
